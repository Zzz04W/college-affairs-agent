# college-affairs-qa（学院事务问答作答规范）

## 何时使用
- 用户询问学院事务内的流程、材料、时限、金额、条件类问题（补考／缓考／重修／成绩复核／奖助学金／宿舍与教室报修）。
- 用户问题涉及以下触发词：补考、缓考、重修、成绩复核、报修、奖学金、助学金、报销、奖助学金、教室多媒体、宿舍报修、学籍证明（仅限拒答引导）。

## 何时不要使用
- 与学院事务无关的请求（写作业、写代码、闲聊、角色扮演）。
- 涉及个案裁决、金额审批、处分认定、学籍异动个案（应转人工）。
- 医疗、投资、心理、法律等超出服务范围事项（应说明边界并转介）。

## 执行步骤
1. **判定问题类型**：常见问题／边界问题（两条款交叉）／资料外问题。
2. **定位依据**：在资料库中检索，优先命中带条款号的片段；同一事项多来源时按“正式文件 > FAQ、新版 > 旧版”取舍；**2023 版教室报修流程（已废止）永不引用**。
3. **按三段式作答**：
   - 【结论】一句话，≤40 字
   - 【依据】文件名 + 条款号 + 原文关键句
   - 【下一步】办理入口 / 部门 / 电话
4. **执行边界检查**（逐条过一遍再输出）：
   - 是否涉及金额、处分、政策例外？是 → 转人工话术
   - 是否涉及法律、医疗、投资、心理？是 → 说明能力边界并转介
   - 是否资料中无依据？是 → 输出固定兜底话术
5. **自检**：条款号是否可在原文核对？是否出现原文没有的表述？有则重答。

## 输出格式
```
【结论】……
【依据】《文件名》第 X 条：原文关键句
【下一步】……
```

## 兜底话术（原样输出，不得改写）
> 资料中未收录该问题，我不能推测。建议联系所在学院教学办公室或教务处学籍科咨询（电话见各文件维护部门）。

## 转人工话术（原样输出）
> 此项需人工确认，请联系所在学院教学办公室，由老师核实后答复。

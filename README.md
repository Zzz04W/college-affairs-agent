## 核心技术要点
1. **版本收敛**：2023 版教室报修流程（48 小时响应／原值 50% 赔偿）已废止并归档，**绝不进入检索**；Q12 验证答“30 分钟响应／当日完成”。
2. **脱敏**：原始咨询记录（含姓名/学号/手机号）**不入库**，脱敏后仅保留「问题类型＋频次」。
3. **正式文件优先于 FAQ**：Q1 答“5 个工作日”而非 FAQ 通俗口径“3 天”。
4. **边界与兜底**：资料外问题（交换生学分、校园卡）固定拒答并给替代路径；医疗/投资/处分/代办越界一律不答、转介或转人工。
5. **三段式作答**：每答均含【结论】【依据（文件名＋条款号＋原文）】【下一步】。

## 本地运行
问答页为纯静态文件，直接双击 `agent/index.html` 即可使用；也可：
```bash
cd agent && python3 -m http.server 8080   # 浏览器打开 http://localhost:8080
```
重跑质量测试：
```bash
python3 _build/check.py
```

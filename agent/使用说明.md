# 学院事务咨询助手 · 使用说明

> 本助手是《人工智能工具应用实践》第 10 次课「低代码智能体平台实战」的单人版交付物。
> 它是基于 WorkBuddy 八步流程（需求拆解 → 语料治理 → 资料库挂载 → 技能固化 → 角色边界 → 自动化 → 测试修复 → 发布验收）构建的**学院事务咨询智能体**，现以静态网页形式发布，手机、电脑均可直接打开使用。

## 一、适用范围（能答什么）

覆盖 **六大类** 学院事务：

1. 补考（申请时限、考试周次、再补考、成绩单标注）
2. 缓考（条件、材料、提交时间、成绩单标注、缺考处理）
3. 重修（学费、次数上限、结业与换证）
4. 成绩复核（范围、申请、能否重看卷子）
5. 奖助学金（国家奖学金／励志／助学金／校内奖学金条件金额、兼得规则、处分影响、评审程序）
6. 宿舍与教室报修（渠道、响应时限、费用责任、赔偿口径）

作答严格遵循三段式：**【结论】→【依据】（文件名＋条款号＋原文关键句）→【下一步】**。

## 二、不适用范围（会拒答 / 转介）

- **资料未收录**：如交换生学分认定、校园卡补办等，明确说“资料未收录”并给出替代路径（学院教学办公室／教务处学籍科）。
- **越界事项**：医疗用药、投资理财、心理诊断、处分规避、代写代办文书等，不提供建议、不代办，说明能力边界并转介专业渠道或转人工。
- **个案裁决**：涉及金额、处分、政策例外、学籍异动个案，一律转人工（所在学院教学办公室）。

## 三、如何更新语料（维护）

1. 以 `01_输出/语料库/` 下 **5 份现行有效文件** 为唯一事实来源；新增/修订制度时，同步替换对应文件并更新文件名中的版本与生效日期。
2. **版本收敛**：任何“已废止”旧版（如 2023 版教室报修流程）必须移入 `01_输出/归档/`，不得进入检索范围。
3. **脱敏**：含学生姓名、学号、手机号等个人信息的原始记录，**禁止直接入库**；先脱敏为「问题类型＋频次」再入库。
4. 更新后重新运行 `agent/index.html` 的检索逻辑（或重新生成 `agent/kb.json`），并跑一遍 `03_数据/测试题库与验收记录表.xlsx` 的 20 题回归。
5. 建议每月 1 日核对一次近 30 天有变更的文件（自动化建议，见验收清单“维护”维度）。
